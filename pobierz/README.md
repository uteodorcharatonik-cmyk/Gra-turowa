# ARX 1.1 — pliki do pobrania

Aplikacje przygotowano z przesłanego pliku **ARX_8.html**.

Otwórz plik i wybierz **Download raw file** (ikonę pobierania). Repozytorium jest prywatne, więc musisz być zalogowany na konto z dostępem.

- [ARX.apk](ARX.apk) — instalacja na Androidzie 8.0 lub nowszym; wymagany aktualny Android System WebView z WebGL.
- [ARX.aab](ARX.aab) — paczka do Google Play, nie do bezpośredniej instalacji.
- [ARX-Windows-x64.exe](ARX-Windows-x64.exe) — przenośna aplikacja Windows x64; F11 przełącza pełny ekran. EXE nie ma certyfikatu wydawcy.
- [SHA256SUMS.txt](SHA256SUMS.txt) — sumy kontrolne plików.

Three.js jest dołączony lokalnie, więc gra działa bez internetu. Zachowano identyfikator aplikacji Android `pl.arx.game` oraz wcześniejszy klucz podpisu. Wersja Androida: 1.1, versionCode 2.

Sprawdzono uruchomienie trybu solo w widoku mobilnym i podzielonego ekranu w Chromium bez błędów JavaScript, zgodność zasobów z ARX_8.html, podpis APK, poprawność i podpis AAB oraz integralność archiwum EXE. Nie testowano uruchomienia na fizycznym Androidzie ani w Windows.

Klucz podpisywania Androida nie jest częścią repozytorium.
