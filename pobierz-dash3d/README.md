# Dash 3D — Windows x64

Aplikacja przygotowana z pliku **Dash_3D_v4.html**.

Otwórz [Dash-3D-Windows-x64.exe](Dash-3D-Windows-x64.exe) i kliknij **Download raw file** (ikonę pobierania). Repozytorium jest prywatne, więc wymagane jest zalogowanie do GitHub na konto z dostępem.

- Wersja przenośna: uruchom pobrany EXE, instalacja nie jest wymagana.
- Gra działa offline; Three.js jest dołączony lokalnie.
- F11 przełącza pełny ekran.
- Postępy są zapisywane lokalnie w profilu aplikacji na danym komputerze. Zapisy z przeglądarki nie są automatycznie przenoszone.
- EXE nie ma certyfikatu wydawcy.

Weryfikacja: uruchomienie rozgrywki i przywrócenie zapisu po ponownym otwarciu w Chromium bez błędów JavaScript, zgodność zasobów wewnątrz paczki oraz integralność archiwum EXE. Nie wykonano testu uruchomienia w Windows.
